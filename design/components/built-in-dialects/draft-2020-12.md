# 2020-12

`src/dialects/draft-2020-12` (`draft202012Dialect`) brings 2020-12's
`$dynamicRef` and `type`, and carries its vocabularies (`vocabularies`), so
meta-schemas that extend 2020-12 with `$vocabulary` can use them. Its `type` can be an empty array, which the drafts allow and v1
doesn't. draft-04 through 2019-09 use it too. `$dynamicRef` resolves
like `$ref`, and if the schema it resolves to has a dynamic anchor named
by the fragment, the outermost schema in the dynamic scope with that
anchor applies instead.
